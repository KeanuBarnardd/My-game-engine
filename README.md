# Game Engine

A learning project. The technology choices below may change as I learn.

- **Window/Input** — [Silk.NET](https://silk.net/): modern, cross-platform C#.
- **Graphics** — OpenGL via [Silk.NET](https://silk.net/): suitable for drawing 2D textured quads.
- **Math** — `System.Numerics`: built-in types like `Vector2` and `Matrix3x2`.
- **Image Loading** — `StbImageSharp`: pure C#, no native dependencies.
- **Audio** — Silk.NET.OpenAL for cross-platform audio, or NAudio for Windows.
- **UI (later)** — [ImGui.NET](https://imgui.net/) for an editor.
